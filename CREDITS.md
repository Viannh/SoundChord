## Maintainer
- **Viannh**: Creator and maintainer of SoundChord for macOS (SwiftUI/AppKit macOS 15+ client, zero-dependency Rust DSP chord/beat/section analysis crate, Apple Music Light & Spotify Dark themes, multi-platform URL playlist importer, and macOS packaging).

## Upstream Inspiration & Attribution
- **BitChord** (`kushagrasinghx/BitChord`): Created by Kushagra Singh (`kushagrasinghx`) and contributors under GNU GPLv3. Repository: https://github.com/kushagrasinghx/BitChord
  - SoundChord for macOS began as an independent native macOS port inspired by BitChord and shares compatibility with the BitChord HTTP Addon protocol.
